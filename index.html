oriz Color

Color studio — picker, palettes, gradients, WCAG contrast, and AI palette. A free, 100% in-browser tool. This page tells you what the project is; the tool itself lives at color.oriz.in.

Open the live app → Source on GitHub llms.txt

What it is

A single-page color studio: pick and convert colors, build palettes and gradients, check contrast against WCAG, and lift a palette straight out of any image — all without leaving the browser.

Key features

Pick + ConvertNative picker; live hex / rgb / hsl / oklch, copy any format.
PalettesComplementary, analogous, triadic, tetradic, split-complementary, monochromatic, shades + tint/shade ramp. Optional AI "brand → palette".
GradientMulti-stop, angle control, oklch / oklab / hsl / srgb interpolation, CSS export.
ContrastWCAG 2.1 ratio with AA / AAA (normal + large) and UI 3:1 matrix, live preview.
ExtractDrag-drop an image, quantize 3–12 dominant colors locally on a canvas.
Convert everywhereCopy any color as hex, rgb, hsl, or oklch.

Tech

  • Client-only Astro static site with React 19 islands
  • Optional AI palettes via g4f, through @chirag127/oz-ai — keyless, in-browser
  • PWA-installable, works offline for the core tools
  • 100% in your browser — no upload, no signup, no server
